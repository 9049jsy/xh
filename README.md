# 아직, 보내지 못한 말

김정수의 가상 휴대폰을 탐색하는 인터랙티브 이야기 체험판입니다. 외부 API, 패키지 설치, 인증 정보 없이 Node.js 24에서 실행됩니다.

## 실행

```sh
cd /workspace/xh
npm run dev
```

기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. `npm run check`는 JavaScript 구문을 검사합니다.

## 체험 흐름

Safari 검색 기록 → 지식인 답변 → 주연이에게 이별 전송 → 주연이의 진심 확인 질문 → 정수의 재확인 전송 → 주연이 답장 → 형준이 연락 → 승민이 연락 → 주연이 이전 기록 탐색 → 승민이에게 부탁 → 주연이에게 사과 → 첫 장 종료.

상황에 맞는 대사가 입력창에 자동으로 표시되며, 전송 버튼을 눌러야 전송됩니다. 대사 선택이나 직접 편집은 하지 않습니다. 답장은 잠시 기다리면 도착합니다. 메모·기억 카드·이전 카톡은 자유롭게 탐색할 수 있습니다. 진행은 현재 브라우저의 localStorage에 저장됩니다. 홈 화면 또는 PC 안내의 ‘처음부터’ 버튼으로 초기화합니다. 사진은 설명 카드이며 실제 메시지·전화는 전송되지 않습니다.
