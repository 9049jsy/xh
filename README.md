# OFF STAGE — 승민의 iPhone

자유롭게 구경하는 팬메이드 가상 휴대폰입니다. 대화·팬 게시물·일정·사진 설명은 실제 사생활 기록이 아닌 창작 설정입니다.

## 실행

Node.js 24만 필요하며 외부 패키지·API·인증 정보가 필요하지 않습니다.

```sh
cd /workspace/xh
npm run dev
```

기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. `npm run check`는 모든 JavaScript의 구문을 검사합니다. GitHub Pages에는 index.html, app.js, details.js, style.css가 같은 경로에 배포됩니다.

## 체험

- 순서와 미션 없이 잠금 화면에서 홈으로 들어가 앱을 탐색합니다.
- 연락처: 지슥이 / 피의 기사 혈준 / 쭈 / 엉덩수. 멤버 단톡방과 개인톡에서 미리 입력된 메시지를 전송할 수 있습니다.
- 사진 슬롯 48개와 분류, 즐겨찾기, 빈 최근 삭제, 배경 색감 선택을 지원합니다. 실제 사진은 아직 없으며 임시 화면입니다.
- Lightroom·VSCO·SNOW 아이콘이 각각 보정 화면을 엽니다. 노출·따뜻함·대비 값을 조절하고 사진 슬롯별로 저장합니다. 실제 이미지를 넣으면 이미지 기반 보정으로 교체할 수 있습니다.
- 메모: 메뉴·지역 후보 18개의 먹킷리스트, 착장, 운동, 신스. 먹킷리스트 체크는 저장됩니다. 가게 영업·예약 정보는 제공하지 않습니다.
- Safari: 맞춤법 3종, 패션·음식·신스 검색 기록과 열린 탭. 지식iN은 가상 질문/답변 UI입니다.
- bubble과 X는 로컬 연출입니다. 실제 서비스 계정에 연결하거나 메시지를 전송하지 않습니다. X 좋아요·북마크를 저장합니다.
- 알람: 14:00 사이클, 16:00 픽업시간. 토글은 이 앱에만 적용됩니다.
- 신스 노트·음성 메모: Web Audio로 만든 약 3초의 오리지널 코드 샘플을 재생합니다. 멤버 녹음이나 연주를 사용하지 않습니다.
- 앱 3개를 탐색하고 약 11초 후 지슥이에게 전화가 옵니다. 22초 동안 받지 않거나 거절하면 부재중으로 남습니다. 전화 앱에서 다시 걸 수 있습니다. 받으면 약 35초 동안 통화 대본이 진행됩니다.
- 실제 음성 녹음은 준비되지 않았습니다. 한국어 시스템 음성이 있는 브라우저에서는 버튼으로 대본을 기본 음성으로 읽을 수 있습니다. 멤버 목소리를 복제하지 않습니다.

진행 상태는 `seungmin-phone-v1` localStorage 키에 저장됩니다. 이전 정수 폰의 데이터와 별개입니다. PC 안내의 ‘처음부터 구경하기’로 초기화할 수 있습니다. 브라우저·기기 간 동기화는 없습니다. 다른 앱 탐색 중에도 수신 전화가 표시됩니다.

## iOS 스타일 UI

잠금 화면의 날짜·시계·위젯, 상태 표시줄, 홈 앱 아이콘·독, 기본 앱별 색상, 전화 수신·통화 중 화면을 iOS 스타일로 구성했습니다. 홈의 검색은 설치된 가상 앱을 필터링합니다. 잠금 화면을 위로 쓸어올리거나 홈 바를 누르면 홈으로 이동합니다. 홈의 ‘처음부터’에서 모바일에서도 초기화할 수 있습니다.

시계의 다른 탭, 통화 추가·FaceTime·실제 스피커 라우팅 등 제공하지 않는 시스템 기능은 비활성화되어 있습니다. 잠금 화면의 조명은 화면 안의 밝기 연출이며 실제 손전등을 켜지 않습니다. 사진 바로가기는 사진 보관함을 엽니다. 통화 키패드는 화면 속 숫자 입력 연출만 제공하며 실제 전화를 걸지 않습니다.
